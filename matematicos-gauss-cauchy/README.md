# Matemáticos que transformaron el mundo: Gauss y Cauchy
Sitio estático (HTML, CSS y JavaScript puro). MathJax y Chart.js se cargan desde CDN (jsDelivr), por lo que se necesita conexión a internet.

## Ejecutar
Abre `index.html` en el navegador.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube el contenido de esta carpeta (con `index.html` en la raíz).
2. Ve a **Settings → Pages**.
3. En **Source** elige *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
4. Guarda; en uno o dos minutos el sitio estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
